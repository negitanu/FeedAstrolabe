# 元版との機能差・移植計画

参照元は `../..` の README、AGENTS、OpenSpec（アプリ0.16.1 / DB schema19）。その実データ・秘密情報は使用していません。現在は統合後の0.1.0です。元版のフル機能移植を最終目標としており、完了判定と段階は full-port-plan.md に記録します。

## 実装済み（0.1.0〜0.2.0）

- Go / SQLite による独立ライブラリ。Electron 子プロセスの起動・認証・終了管理。
- RSS / Atom の公開URL取得、HTML alternate による発見、プレビューと購読、定期／手動更新、重複排除と失敗時の保持。
- フォルダー、名前変更、D&D・上下移動、フォルダー間移動、停止／再開、削除。ペイン幅と開閉を保存。
- 記事の既読・スター・履歴、フォルダー／情報源／案件による絞込み、リテラル検索、OR／除外／UTC日付／複数情報源条件、公開日／履歴の順序。
- 標準・1行・タイル、スクロール追加、一覧を維持する詳細、条件全体の既読、100件までの選択変更。
- 日本語 UI、ライト・ダーク・システム連動、UTC／JST、OPML入出力。
- 案件の作成・アーカイブ・再開、版管理Markdownメモ、競合拒否、記事関連付け、SHA-256付き根拠スナップショット、Markdownレポート。
- 設定JSON、完全JSONバックアップ、トランザクション復元と復元前の自動保存。

- 0.2.0: Mastodonタグ／アカウント、Blueskyキーワード、反応数ランキング・関連タグ・直近30回のSNS履歴、サービス単位429待機、定期収集の全体停止と自動ジョブ停止保護。
- 0.2.0: OpenRouter／OrcaRouterの個別設定、入力・出典を固定した話題抽出、自動抽出、共有予算、永続ジョブ、再送防止。
- 0.2.0: 案件のpublic/internal/restricted、Ollama local/cloudの正確な入力プレビューと承認、ローカルdigest・cloud-disabled検証、固定引用、人のレビュー版。
- 0.2.0: schema1からの事前バックアップ付き移行、backup1/2、AI設定を含む秘密情報なし設定JSON、復元後のAI無効化・未完了ジョブ失敗化。

## 振る舞い・形式の違い

- 現変更では記事本文を安全なHTMLとして表示します。外部画像・埋め込み・OGP画像は取得しません。
- デスクトップ専用です。Electron の最小幅は680pxで、720pxの狭いウィンドウまで検証します。スマートフォンへの提供はありません。
- データ形式は本アプリ専用です。元版の SQLite を直接開いたり、そのバックアップを復元したりしません。購読は OPML で持ち出せます。
- メモ版履歴と根拠は保持しますが、添付ファイル・公開区分・案件タグは未実装です。
- 設定JSONは表示・収集間隔・AI接続設定を含みます。キー・資料・ジョブ・日次消費は含まず、読込み時はAIを無効にします。

## 今回の sync-local-web で未完了の移植項目

1. 元版からの記事・既読・スター・案件・根拠の移行ツール。元版DB schemaごとの読取専用アダプター、整合バックアップと移行レポート。
2. SNS・AIの主要経路は実装済み。残差はOllamaの複数名前付きprofile、個別の予算台帳、元版の完全な保持・細部UI互換性。現版はlocal/cloud各1設定、全接続共通UTC予算、ジョブ表示は直近100件（DB上限1万件）。
3. 隔離 renderer を使う JavaScript ページ観測。安全なリソース仲介と差分保存。
4. 案件タグ・公開区分・添付来歴・引用管理の拡張、保存検索・ウォッチリスト・受信箱・日次ダイジェスト・重複整理。
5. 対象と関係、グラフ／タイムライン、セキュリティ・ネットワーク・AI研究の専門情報連携。
6. Ollamaの主要経路は実装済み。実モデル品質の受入、Windowsでのクラウドtoken ACL確認、案件全対象への分類・引用位置検証拡張は未完了。
7. 通知・運用レポート、世代バックアップの運用、スコープ付き公開API。ローカルUI用のRPCは公開APIとして提供しません。
8. 各OS実機・アクセシビリティ検証、アイコン・コード署名・macOS公証、自動更新。

未完了項目は最終移植対象です。各機能差を更新し、個別の proposal / design / specs / tasks から実装を継続します。SNS・AIの有料生成は模擬HTTPのみの検証で、実サービス受入とは区別します。

## sync-local-web の現在地

購読/記事/既読/スター/収集状態の双方向同期、任意のAccessセッション、オフライン再送、RSSの情報源別間隔、安全な記事HTML、JSON v3を追加しました。調査データ・UI順序・秘密・AIジョブ/予算は同期しません。上の未完了項目は今回の変更に含めて追跡し、全機能移植の受入は未達です。既存の0.1/0.2検証履歴とは分けて [最新の検証記録](verification-library-sync.md) を参照してください。
