# 操作手順

## 購読から読書まで

1. 「集める」でサイトまたは RSS / Atom の URL を入力し、「候補を確認」を押します。
2. フィード名と最新記事のプレビューを確認し、名前・フォルダーを指定して「購読する」を押します。確定時に初回の記事を取得し、その情報源の記事一覧へ移動します。
3. 記事のタイトル・説明を押すと詳細が開き、既読と履歴を保存します。タイトルで元記事を既定ブラウザーに開けます。本文の HTML や外部画像は実行・読み込みせず文字として扱います。
4. 詳細の前後移動で記事を読み、× または Escape で閉じます。詳細を開閉しても追加読み込み済みの記事と一覧位置は保持します。

取得できない場合は「⋯」→「名前・設定を編集」で最終エラーを確認できます。失敗しても保存記事は残ります。アプリ停止中は定期更新しません。「設定」→「定期収集を停止する」で全体の自動更新も止められます。更新間隔の変更は次の収集周期から反映されます。

## フォルダー・購読の整理

情報源見出しの「＋」でフォルダーを作成します。名前のクリックは所属記事の表示で、矢印のクリックは開閉です。左ペインの行はドラッグで並べ替えられます。フィードをフォルダーへ落とすと移動します。「⋯」→「名前・設定を編集」のフォルダー選択でも移動できます。上下の並べ替えは「⋯」のメニューからキーボードでも可能です。

購読停止は新規収集だけを止めます。保存記事・既読・スターは保持し、再開できます。「購読と記事を削除」は既読・スターと記事関連付けも削除しますが、保存した根拠は残します。フォルダー削除は中のフィードを「フォルダーなし」へ移動します。

左ペインと本文の間の境界をドラッグすると幅を変更します。境界へ Tab で移動し、左右キーでも変更できます。狭い画面ではペイン幅を固定して本文の横はみ出しを防ぎます。

## 検索と状態

検索欄はタイトルと本文のリテラル部分一致です。`%` や `_` は SQL ワイルドカードになりません。「詳細検索」で対象、複数の情報源、カンマ区切りの OR 条件と除外語、公開日の範囲を組み合わせます。日付条件は UTC の日付で、終了日はその日の終わりまでを含みます。英字の大小文字は区別しません（SQLite標準のASCII範囲）。

記事は公開日と ID で順序を決め、スクロールで60件ずつ追加表示します。表示件数のユーザー向け上限やページ番号は設けていません。「未読」への切替はフォルダー／情報源などの選択条件を解除し、全ライブラリの未読を表示します。

チェックで最大100件を選択し、既読・未読・スターを変更できます。「全て既読」は現在のフィルター全体に対し実行します。未読一覧の詳細を読んだ直後も、本文はそのまま表示されます。

## 案件・メモ・根拠

「調べる」→「案件を作成」で案件名を入力します。メモには Markdown を入力し、「メモを保存」で新しい版を残します。事実・情報源の主張・仮説を区別して書くと整理できます。下部の版履歴で過去のメモを確認できます。古い版を別ウィンドウから保存した場合は競合として拒否し、保存済みの内容を上書きしません。

記事詳細の「調査案件・根拠」で案件を選び、「関連付け」または「根拠を保存」を押します。根拠保存は関連付けも行い、記事のその時点のタイトル・URL・本文・取得時刻・SHA-256 を固定します。原記事が後から変わっても根拠は変更しません。根拠番号 `[E1]` などをメモに書くと、レポート内の出典を指せます。ハッシュは `タイトル + 改行 + URL + 改行 + 本文` の UTF-8 バイト列に対する SHA-256 です。

案件はアーカイブ／再開できます。アーカイブ後もメモ・根拠・レポートは残ります。「まとめる」で Markdown を保存します。メモの Markdown はアプリ内で HTML として実行しません。外部の Markdown ビューアーでは、そのアプリ側の安全な設定を使ってください。

## OPML・設定・復旧

OPML の「選択」後は、追加予定・重複・無効URLを確認し、「この内容で追加」で確定します。取り込んだ情報源の記事は「更新」で取得します。ネストしたフォルダーは `親 / 子` の1段の名前として保持します。購読の停止状態や記事は OPML に含まれません。

設定 JSON は表示・収集間隔・AI接続設定を含み、キー・資料本文・ジョブ・日次消費は含みません。完全バックアップ JSON は本文・状態・案件・版・根拠も含みます。復元は置き換え操作なので、ネイティブ確認ダイアログで明示的に確定します。復元前の安全コピーの保存が失敗した場合は復元しません。形式・参照・設定・根拠ハッシュが不正な JSON は、全変更をロールバックします。

## SNS・AIの追加操作（0.2.0）

SNS登録、公開投稿の順位とタグ、プロバイダ別の接続設定、UTC共有予算、Ollamaの根拠選択・プレビュー・承認・レビューは [SNS・AIの手順](social-ai.md) を参照してください。案件の公開区分を変更するとメモと同じ案件版が進み、変更前のプレビューを送信しません。

設定JSONはバージョン2でAIの接続設定を追加しました。キーや日次消費を含まず、読込みではAIを無効にして既存の予算台帳を保持します。完全JSONのバージョン2はSNS・AIの履歴と台帳も含み、バージョン1も引き続き復元できます。

## Web 同期・形式 v3

同期は初期状態で停止しています。設定から接続先を入力し保存、必要なら接続先を開いてAccess認証後に同期します。[同期範囲と再送](library-sync.md)を参照してください。設定JSON v3は同期先URLを含み、読込みでは同期を停止します。完全JSON v3は情報源ごとの収集間隔も保存し、復元後は接続先を解除します。v1/v2は引き続き読み込めます。上のv2記述は0.2.0時点の履歴です。
