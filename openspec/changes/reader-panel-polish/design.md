## Context

固定配置の詳細をfragmentで交換し、記事一覧とスクロール位置を維持する。外側のフォームやリンクも通常どおり操作できる必要がある。

## Goals / Non-Goals

開閉を自然にし、リーダーの選択欄とブランド表示を統一する。DB/APIや記事状態の意味は変えない。

## Decisions

- 外側クリックでは詳細用URLパラメーターとハッシュだけを取り除き、ローカルに閉じる。閉じるためのHTTP待ちを避ける。元のクリックはキャンセルしない。他の記事タイトルは既存の詳細切替を優先する。
- Web Animations APIで180msの透明度と短い横移動を使う。閉じるパネルは直ちにinertとし、完了後に削除。新しい操作時は古いアニメーションをキャンセルする。初期表示とブラウザー履歴にも適用し、reduced-motionでは即座に切替える。
- 取得中の詳細レスポンスを世代番号で無効化し、保存中に外側で閉じても古いレスポンスが詳細を開き直さないようにする。
- 八方向のSVGをヘッダーのCSSマスクとfaviconで共有する。文字フォントや絵文字の環境差をなくす。selectは既存入力ルールを共用する。

## Risks / Trade-offs

- 外側操作と閉じる処理の競合 → クリックを抑止せず、記事切替と保存後描画の世代を検証する。
- 動きへの負担 → prefers-reduced-motionでアニメーションを省略。
- faviconキャッシュ → 新しい静的ファイル名を使用。ブラウザー標準のSVG対応を使う。

## Migration Plan

DB移行なし。既存コンテナを再構築し、healthと静的配信を確認する。必要時は直前のソース／イメージに戻す。
