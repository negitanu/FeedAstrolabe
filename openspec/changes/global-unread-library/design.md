## Context
ライブラリの未読リンクへfolderが渡り、未読件数もフォルダーに限定されている。通常表示と閲覧POSTに件数処理が重複している。
## Goals / Non-Goals
**Goals:** ライブラリの未読を全記事に統一し、通常表示と詳細表示後の未読バッジを一致させる。
**Non-Goals:** 他のライブラリ表示条件や明示的なフォルダー条件、既存記事の状態の変更。
## Decisions
未読リンクはview=unreadだけを渡す。未読バッジは常に全記事から集計し、通常表示／閲覧POSTで共通の件数関数を使用する。フォルダーやフィードに限定された未読表示ではグローバル未読ナビゲーションを選択中にしない。検索やフォルダーの明示的な組合せ条件は引き続き利用できる。
## Risks / Trade-offs
- 表示と更新後のバッジが異なる → 件数取得を共通化し、表示と閲覧POSTを回帰テスト。
## Migration Plan
DB変更なし。コンテナ再構築・再起動後、healthとHTTPで入口と件数を確認する。
