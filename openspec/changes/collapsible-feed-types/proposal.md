## Why
A long mixed subscription list is difficult to scan. Users need independently collapsible feed types.
## What Changes
- Group sidebar subscriptions by RSS/Atom, X, Mastodon and page observation.
- Provide native accessible disclosure controls with subscription and unread counts.
- Preserve folder grouping, links and current-feed highlighting.
## Capabilities
### New Capabilities
- `collapsible-feed-types`: Feed type disclosure groups.
### Modified Capabilities
None.
## Impact
Sidebar template and CSS only; no data migration, script or API change.
