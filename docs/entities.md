# 対象・言及・引用付きの関係

「対象」から CVE、ドメイン、IP、ASN、ハッシュ、GitHubリポジトリを検索できます。組織／製品／モデル名は手動登録します。同名でも別対象を作れ、別名も自動統合しません。ライブラリは共有で、案件フィルターは調査範囲の絞り込みです。権限分離ではありません。

根拠詳細の「対象を抽出」で固定本文から候補を抽出します。workerも収集後に未処理の根拠を最大20件ずつ処理します。候補は未確認です。対象詳細から確認／却下／対象の訂正を行えます。手動言及は根拠ID、対象ID、Unicode文字位置start/end、完全一致の元表記を指定します。元表記・位置・本文ハッシュ・抽出時の対象は変更せず、現在の対象と判断の版を別に保存します。再抽出は人の訂正・却下を上書きしません。

## 正規化と上限

正規化版 `rules-v1-idna2008-uts46` を記録します。識別子の構文を照合し、存在・割当・脆弱性の実在は認定しません。

- CVEは大文字化し、年4桁・連番4〜32桁。[CVE公式の可変長連番](https://www.cve.org/Resources/Media/Archives/OldWebsite/cve/identifiers/syntaxchange.html)に対応します。
- IPは[Python ipaddress](https://docs.python.org/3/library/ipaddress.html)の厳密解析と圧縮IPv6。先頭ゼロIPv4、zone、CIDRは対象識別子として拒否します。
- ASNはASと0〜4294967295の数値。予約番号も構文上は受け付け、[IANAの割当状況](https://www.iana.org/assignments/as-numbers)と区別します。
- ドメインは[idna 3.20](https://pypi.org/project/idna/3.20/)のIDNA2008／UTS46、STD3、non-transitional処理でASCII化。`faß.de`と`fass.de`を区別します。[Unicode TR46](https://www.unicode.org/reports/tr46/)に沿った変換で、ラベル63文字・全体253文字まで。
- ハッシュは32／40／64桁hexを小文字化。長さからアルゴリズムを断定しません。
- GitHubはgithub.comのowner/repoのみ、末尾.gitを除いて小文字化。[公式API](https://docs.github.com/en/rest/repos/repos?apiVersion=2022-11-28)の大小文字を区別しない識別に合わせます。認証情報・query・fragmentを含む入力は拒否します。

抽出は固定ルールのみで、利用者の正規表現やネットワーク問い合わせを実行しません。1根拠500言及／2000候補試行まで。上限に達した根拠はAPIと画面で省略を表示します。再試行で500件を超えません。手動別名は1対象100件、統合の深さ20、統合familyは500件までです。すべての一覧はcursor／画面ページ送りで取得します。

## 関係・監査

案件内の固定引用を先に作り、表示された引用IDを使って関係を追加します。対象2つ、関係の語句、引用、事実／情報源の主張／仮説、確信度、記録者、任意のUTC観測日時・有効期間を保存します。確信度は人の判断で、統計的な確率ではありません。記録者も自己申告です。別案件の引用、不正な期間、古い版の編集は拒否します。編集は新しい不変版を作り、旧版も閲覧できます。

同じIPへの言及は所有者や攻撃者の同一性を意味しません。グラフは人が記録した引用付き関係を描き、深さ0〜2／最大200対象・400関係に制限します。省略フラグがある場合は関係一覧とタイムラインのページ送りで確認します。アーカイブした関係はグラフから除きます。

手動統合は同種の対象に限り、確認チェック・理由・現行版を要求します。元対象を代表対象へ参照させ、言及・関係の元IDを変更しません。「統合を取り消す」でその参照を解除し、両操作を監査に残します。競合は409です。案件のアーカイブ後は関係編集を停止し履歴は読めます。

言及・監査・関係から参照される根拠は保存期間による削除から保護します。却下した言及も元の位置を保持します。対象メタデータの一括purgeは提供していないため、長期運用の保存期間管理は後段で扱います。

schema v7からv8への更新前にwriterを停止してbundleを保存してください。v6／v7 bundleの復元は現行v8へ移行します。v8 bundleは元の言及位置／本文ハッシュと、関係の引用／案件整合性も検証します。[復旧手順](evidence.md)を参照してください。
