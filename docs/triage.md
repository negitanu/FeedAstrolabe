# ウォッチリスト・保存検索・整理

案件詳細の「ウォッチリスト・受信箱」から条件を保存します。新規作成では本文／タイトル／情報源名／URLに対するキーワードを1行ずつ入力し、いずれかに一致する根拠を対象にできます。除外キーワードは本文で照合し、除外を優先します。空の包含条件は案件内の全根拠を対象にします。優先度と理由は人が設定し、通知に保持します。

ウォッチリストと保存検索のどちらも、自動照合の設定と読み取りのプレビューを持ちます。APIの保存検索は初期状態で自動照合が停止し、画面ではチェック欄で選択します。`worker` は収集後、10秒tickで最大20条件・各100根拠を処理します。古い処理時刻を優先して、21条件目以降も順番に処理します。収集する情報源がない場合も照合します。単独の1バッチは次のコマンドで実行できます。

```sh
.venv/bin/python -m flask --app feedastrolabe triage
```

対象は案件へ関連付けた情報源・記事・固定根拠・案件内メモへの固定・引用の和集合です。新しい版は増分で照合します。既存のタグ・案件への関連付けを変更した場合は「先頭から再照合する」を実行します。自動照合停止時は「続きの100件を照合する」で進められます。アーカイブした案件は自動／手動処理・条件編集が停止し、履歴を閲覧できます。

条件編集は新しい版を作り、過去の包含／除外・優先度・理由を保持します。APIは expected_revision を必須にし、同時編集は409を返します。同じ条件版・根拠版の再照合では通知を再発行せず、確認状態も維持します。記事の既読・スターと受信箱の確認状態は別です。

## 詳細条件

編集画面とAPIでは shallow JSON を使用できます。包含と除外の合計40条件、各JSON2000文字、値200文字、案件の保存条件100件まで。正規化したJSONで上限を判定します。

```json
{
  "all": [{"field":"source_type","op":"eq","value":"rss"}],
  "any": [{"field":"text","op":"contains","value":"CVE-"}],
  "none": [{"field":"title","op":"contains","value":"広告"}]
}
```

allは全一致、anyはいずれか一致、noneはいずれも一致しない条件です。空のall／any／noneはその条件を制限しません。空の除外条件は除外を無効にします。title/text/publisher/urlはUnicode casefoldでcontainsまたはeq、tag/source_typeはeq、published_at/captured_atは実在するUTC日時 `YYYY-MM-DD HH:MM:SS` のeq/gte/lte。source_type はrss/x/mastodon/page/attachment/unknownで、削除済みRSS/SNS情報源はunknownとなります。公開日時不明は日時条件に一致しません。任意のSQL・正規表現は受け付けず、%や_も文字として検索します。

受信箱には採用／除外と各条件の一致／不一致、優先度の理由、条件と根拠の版を表示します。日次ダイジェストは指定UTC日付に作成した採用通知です。再照合で過去の根拠から新しい条件版の通知を作る場合、再照合日のダイジェストへ入ります。メールやWebhookは送信しません。

## 重複グループ

異なる情報源identityの完全一致テキスト、または同じ正規化URLを自動でグループ化します。URLではfragment、utm_*（大文字小文字を区別しない）、fbclid、gclidだけを除き、その他のquery・重複したquery・空の値を維持します。URLの一致は本文の一致を意味しません。グループ詳細でそれぞれの出典・版・元の記事状態を確認できます。

「グループを解除する」は表示のグループ化を抑制します。自動処理で解除を取り消さず、手動で再び有効にできます。元の根拠・購読・記事・既読・スターを削除／統合しません。近似重複は今回扱いません。参照を保つため、通知と重複グループにある根拠も保存期間の削除対象から外れます。通知／グループの保存期間設定は後段で扱うため、容量上限の管理に留意してください。

schema v7への更新前にはv6のbundleを保存し、全writerを停止します。旧v6 bundleの検証付き復元にも対応し、復元先をv7へ移行します。条件版・通知・確認状態・解除状態もbundleに含みます。[復旧手順](evidence.md)を参照してください。
