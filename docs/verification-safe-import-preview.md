# 購読プレビューと外部XML対策（2026-10-11）

## 改修

- 設定UIのOPMLアップロードをプレビューに変更。URL・タイトル・フォルダーを文書順に表示し、追加予定、登録済み、ファイル内重複を区別します。確認・取り消しはnativeフォームとリンクで操作し、JavaScriptを必要としません。
- 確認前はDBを変更せず、取得先への通信も行いません。署名付き確認データは用途を限定し、現在のCSRFセッションに照合して15分で失効します。改ざん・別セッション・不正形状・重複パラメーターを拒否し、確定時にもURLと項目の上限を検証します。
- 登録は更新ロックと書き込みトランザクションで実施。確認中に増えた重複はスキップし、実際の件数を通知します。既存のタイトル・フォルダーは上書きせず、同じ確認の再送も重複登録しません。APIの明示的なインポート契約は保持しました。
- RSSのDTD内で宣言した実体が旧実装で展開されることを小さな入力で再現。RSS/Atomの解析前にDTD・実体宣言・外部参照を拒否するストリーミング検証を追加し、バイト数・要素数・深さも制限しました。外部ファイル読み取りが成立したという検証結果ではありません。
- 不正XMLは既存の寛容な解析へ渡さず拒否します。DTDに依存するフィード・整形式でないフィードは取得できなくなります。解析失敗時も既存記事・既読・スターを保持します。
