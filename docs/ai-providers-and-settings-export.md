# AI接続と設定出力

「設定」→「AI接続」でOpenRouter／OrcaRouterを選ぶ。選択した接続先だけのモデル・認証状態・利用上限を表示し、保存すると使用先を切り替える。非選択先のモデル設定も保持する。保存自体は生成を実行しない。

キーは`.env`の `OPENROUTER_API_KEY`／`ORCAROUTER_API_KEY` へ設定して再起動する。キーはブラウザー・設定DB・エクスポートへコピーしない。日次の利用枠は両サービスで共通で、切り替えてもリセットしない。予約済みジョブは元の接続先に固定する。

OrcaRouterは構造化出力に対応するOpenAI／Google／xAIの固定モデルを対象とする。現時点では自動ルーター別名・Anthropicなどの非対応形式を抽出用として有効化できない。OrcaRouter固有の費用フィールドとrequest IDを扱い、即時費用がない場合だけ決済参照GETを最大2回行う。費用不明時は予約額を維持し、生成POSTは自動再送しない。アプリの予約上限が事業者側の課金額を保証するものではない。

「設定をエクスポート」は `feedastrolabe-settings.json` をダウンロードする。形式は `format=feedastrolabe-settings`、`format_version=1`。収集、表示、購読、フォルダー／フィード順序、AI接続、連携・通知・バックアップの非秘密設定、保存検索・ウォッチ設定を含む。現在のブラウザーの外観・幅・記事形式・開閉状態も含む。

APIキー、資格情報、署名鍵、秘密ファイルの内容・場所、資格情報が埋め込まれたURLは除外する。除外した設定欄はnullとなり、`omissions`へ欄名と理由を記す。記事本文、研究資料、生成内容、ジョブ、実行履歴・利用実績は含めない。参照する案件・対象は参照情報として出す。

このJSONは設定の保管・比較用で、設定インポートは含まない。完全な復元は既存のバックアップバンドル、RSS購読だけの移行はOPMLを使う。旧 `/settings/openrouter` はAI接続のOpenRouter選択へ、旧 `/settings/feeds` は記事一覧へ移動する。
