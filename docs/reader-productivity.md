# 読む・集めるの拡張

## サイトからフィードを探す

「集める」→「RSS / Atom」で Webサイトまたは RSS/Atom の URL とフォルダーを入力し、「候補を探す」を選びます。

- Webサイトの場合は HTML の `link rel="alternate"` が宣言する RSS/Atom を最大8候補表示します。候補ごとの「記事をプレビュー」で記事を確認します。
- フィードを直接入力した場合は、そのフィードのタイトル・URL・最新の記事（最大5件）を表示します。
- フォルダーを確認して「購読して記事を読む」で確定します。プレビューの段階では購読・記事を登録しません。確定時に再取得し、既存の購読は重複追加しません。

プレビューは同じブラウザーセッションで15分間有効です。見つからないときはフィードの URL を直接入力してください。サイト名の外部索引検索、JavaScript で生成されるリンクの探索、ログインサイトの取得は行いません。ローカル・プライベートアドレスの拒否、DNS固定、リダイレクト検証、30秒・5MiBの取得上限を引き継ぎます。

従来の直接RSS登録 `/feeds` と公開APIは互換性を維持しています。

## 最近読んだ記事

左ペインの「最近読んだ記事」から、実際に本文を開いた記事を直近の閲覧順に探せます。同じ記事を再び開くと、最新の閲覧日時を更新します。

既読・スターとは独立しています。全て既読、個別の既読・スター変更、API参照、元記事の中クリックでは履歴を追加しません。JavaScript が無効な場合は、本文上部の「閲覧履歴に記録」を押します。保存失敗は本文内で表示します。

履歴はこのアプリの共有ライブラリ全体の情報です。利用者別・端末別の履歴ではありません。記事削除時には対応する履歴も削除します。設定JSONのエクスポートには含めず、完全バックアップには含めます。

## 記事詳細の開閉

記事本文はフロート表示します。パネルの外側をクリックすると閉じます。外側のチェックやリンクもそのまま操作でき、別の記事名を選ぶと本文を切り替えます。閉じても読み込み済み一覧・選択・検索条件・位置を保持します。本文内の操作はパネルを閉じません。

開閉は短いアニメーションで表示し、OS／ブラウザーの「動きを減らす」設定では省略します。JavaScriptが無効な場合は右上の「閉じる ×」を使えます。

## 並び順

検索欄横で「新しい順」「古い順」を選び、「検索」で適用します。「最近読んだ記事」では「最近読んだ順」も選べます。公開日時が同じ場合は記事IDで順序を固定します。

スクロールによる追加読み込み、本文の前後移動、未読への移動にも同じ並びを使います。並び順を変えた場合はその条件で一覧を読み直します。外部での人気度を推測する人気順は提供していません。

## 詳細検索

検索欄の「詳細検索」を開き、必要な条件を設定して「検索」を押します。

- 通常の検索語は従来どおり一つの語句として部分一致します。スペースを自動的に AND 演算子とは扱いません。
- 「検索対象」はタイトルと本文／タイトルのみ／本文のみを選択できます。
- 「いずれかを含む」は1行1語句、いずれか一つを含む記事が対象です。「含まない」はどの行の語句も含まない記事を対象にします。各10行まで、1行200文字、各欄2000文字までです。
- 通常の検索語、追加語句のグループ、除外、期間、情報源、案件・タグは、すべての条件を満たす記事だけを表示します。`%`、`_`、引用符等も通常の文字として照合し、正規表現・SQL・検索演算子は実行しません。
- 公開日の開始・終了は、設定した表示タイムゾーン（UTC/JST）の暦日です。終了日を含み、翌日の0時を含みません。元の公開日時が不明な記事は期間検索に含めません。
- 情報源は複数選択できます。PCでは Ctrl/Command 等を使った標準の複数選択、モバイルではOSの選択操作を利用します。未選択なら全情報源、最大100情報源です。左ペインでフィードを選んでいる場合はその条件とも組み合わせます。

本文の開閉・前後移動、状態変更、追加読み込み、「全て既読」は現在の条件を保持します。不正な日付、逆転した期間、重複や存在しない情報源はエラーになり、状態変更は行いません。検索結果にユーザー向けの表示件数上限はなく、末尾から続きを読み込みます。

## 記事の複数選択

記事右上のチェックで任意の記事を選び、表示された一覧上部の選択バーで操作を選んで「選択した記事に適用」を押します。操作は既読にする／未読に戻す／スターを付ける／スターを外すです。

「表示中を選択（100件まで）」は、現在描画されている記事から最大100件を選びます。「選択を解除」で取り消せます。チェック状態は追加読み込み、本文の開閉、ブラウザー履歴、カードの更新で保持します。別の検索や表示条件へ移ると選択を解除し、操作後に条件から外れた記事も選択対象から外します。

選択操作は最大100記事を一度に更新し、存在しない・重複した・現在の表示条件に含まれないIDが一つでもあれば全件を変更しません。選択していない記事や閲覧履歴には影響しません。JavaScript が無効でもチェックと通常のフォーム送信で更新できます。

**「全て既読」は、選択チェックの有無にかかわらず、未描画記事を含む現在の表示条件全体を対象にします。** 選択バーの操作とは対象が異なります。
