# ドラッグ並べ替え・外観・共通UIの検証

2026-10-24。OpenSpec: `drag-theme-interface-refactor`。

## 実装

- サイドバーとフォルダー設定のドラッグハンドル。Pointer Eventsでマウス・タッチに対応し、移動先の線、画面端での自動スクロールを表示する。
- 既存のCSRF検証・トランザクションを伴う位置変更処理を共有。完了時はサーバーの確定順序を反映し、失敗時は表示を戻す。Escape・pointercancel・移動なしは保存しない。
- キーボードの上下/Home/End、既存の上下ボタン、折りたたみ内の番号指定を併設。JavaScriptなしでも従来操作可能。
- 「設定 → 外観」にシステム・ライト・ダーク。初期値はシステム。CookieはHttpOnly/SameSite=Lax、トンネル環境ではSecure。テーマはブラウザーごと、フォルダー順序はDBで端末間共有。
- `presentation.py`へテーマとnonceを集約。`static/css/`へ意味別の色定義と画面別スタイルを分割。共通通知とドラッグ部品、設定名の定義を統一。
- 装飾英語、二重ブランド、重複見出し、設定カードの補助説明、操作後の定型説明を除去。入力条件、エラー、外部送信と削除の確認は保持。

Chromiumで1280pxと375pxを検証。
