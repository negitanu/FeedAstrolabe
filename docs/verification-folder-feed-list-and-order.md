# フォルダー内フィード一覧と表示順の検証

実施日：2026-10-24（Asia/Tokyo）。対象：`folder-feed-list-and-order`。

## 実装

- サイドバーのフォルダー名から `/folders?folder=...` を開き、所属フィードだけを表示する。
- フィードごとに種別・記事数・未読数・最終確認と、記事／未読／設定への入口を表示する。
- 左矢印の開閉と名前リンクを分離。既存の開閉状態の保存は維持する。
- `/settings/folders` で上・下・指定位置への移動を保存。設定索引とサイドバーから到達する。
- スキーマ17で `folder_positions` を追加。既存のフィード・記事・既読・スターを維持する。
- フォルダーの追加・移動・削除後は現存する名前だけを扱い、新しい名前を保存済み順序の末尾へ追加する。

## 検証範囲

- フォルダー内フィードの完全一致、記事／未読の集計とリンク先。
- 空文字の未分類と「未分類」という名前、英字大小、HTMLを含む名前の区別・エスケープ。
- 存在しない名前、長すぎる名前、重複パラメーター、CSRFなし、位置の範囲外・小数・不正文字列を拒否し、保存値が部分更新されないこと。
- 任意位置と上下移動の順序がサイドバー・設定画面で一致し、アプリ再起動・別セッション・バックアップ復元後も維持されること。
- v16からv17への移行と繰り返し起動、外部キー整合性、記事状態の保持。
- PC 1280px／モバイル375px、JavaScript有効／無効でフォルダー選択→フィード記事→並べ替え→再読込の操作。キーボードのEnterと矢印部分のクリックでURLを変えず開閉できること。
- 保存時の通知と移動先へのスクロール、現在位置、横方向のはみ出し、PC・モバイルのスクリーンショット。
- 既存の検索・既読・スター・前後の記事・開閉保存・他の設定画面・DB移行／復元を含む全回帰。
