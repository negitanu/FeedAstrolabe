# フィード種類の開閉状態の保存（2026-10-11）

## 動作

- RSS / Atom、X、Mastodon、ページ観測の開閉操作をブラウザーのlocalStorageに保存。記事表示、検索条件の変更、再読み込み後も復元します。同じブラウザープロファイル・同じoriginの画面で共有され、別端末には同期しません。
- 保存対象はバージョンと4種類の真偽値のみ。記事内容、フィードID、認証情報は保存しません。不正なJSON、未知のバージョン、配列の状態データ、512文字を超える保存値は無視します。
- 選択中のフィード種類は自動で開きます。その初期展開によるnative toggleイベントで、保存済みの「閉じる」が上書きされないようにしました。明示的な操作だけを保存します。
- 「表示を初期状態に戻す」は保存を解除し、全体表示では全種類、フィード選択時は選択中の種類だけを開きます。URL、記事の既読・スターには変更を加えません。
- 保存が拒否されてもnative details/summaryは操作できます。JavaScript無効時は従来の初期表示と開閉操作を保持し、保存解除ボタンは表示しません。
